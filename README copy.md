# 📦 Unpack

> **Your offline AI survival guide for the first 30 days abroad.**  
> Powered by Gemma 4 via Ollama · No internet required after setup.

---

## What is Unpack?

International students land in a foreign country and immediately face a hundred decisions nobody prepared them for. Tax file numbers, health cover, visa work conditions, bank accounts, rental bonds, academic culture. Unpack is a locally-running AI companion that guides you through all of it — mission by mission, in plain language, with no internet required.

Built for the [Gemma 4 Good Hackathon](https://www.kaggle.com/competitions/gemma-4-good-hackathon) · **Future of Education** track + **Ollama Special Prize** track.

---

## Features

- 🗺️ **Personalised 30-day mission guide** — generated by Gemma 4 based on your country, university, and visa type
- 🆘 **Panic Button** — overwhelmed? Get one single task to focus on right now
- 💬 **Conversational follow-ups** — ask Gemma 4 anything about each mission, with full context
- 📱 **Fully offline** — runs on your laptop with no internet via Ollama
- 💾 **Progress saved locally** — pick up where you left off between sessions

## Quick Start

### 1. Install Ollama
```bash
# Mac / Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows: download from https://ollama.com/download
```

### 2. Pull Gemma 4
```bash
ollama pull gemma3:4b
```
> If your machine is slow, use `gemma3:1b` instead. Update `MODEL` in `app.py` to match.

### 3. Start Ollama
```bash
ollama serve
```

### 4. Clone and run Unpack
```bash
git clone https://github.com/geetanjaling24-rgb/unpack-gemma4.git
cd unpack-gemma4
pip install -r requirements.txt
streamlit run app.py
```

Open your browser at **http://localhost:8501**

## Docker (full offline experience)

```bash
docker-compose up
```

This starts Ollama + pulls Gemma 4 + runs the Streamlit app — all in one command.

## Architecture

```
User input (profile)
        ↓
Student profile layer (country · university · visa · year)
        ↓
Gemma 4 via Ollama REST API (localhost:11434)
  ├── Mission generation (structured JSON output, few-shot prompted)
  └── Conversational support (full context per mission)
        ↓
Streamlit frontend
        ↓
Local JSON persistence (progress saved between sessions)
```
